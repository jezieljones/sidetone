# Sidetone

This is the standalone self-hosted Sidetone repository. Never copy production credentials, deployment links, or customer data into it. Keep telephone and meeting sources optional. Preserve authentication and owner isolation when changing billing behavior. Read `apps/sidetone/convex/_generated/ai/guidelines.md` before Convex changes. Bound database reads. Run `npm test`, `npm run typecheck`, `npm run build`, and `npm run scan:secrets` before release. Live provider tests must use the operator’s explicit test accounts.
